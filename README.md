# 4ccEditor GV Bulk Tools

**A fork of [4ccEditor](https://github.com/the4chancup/4ccEditor), focused on bulk player data operations for Pro Evolution Soccer 2021 save files.**

## About

4ccEditor GV Bulk Tools is a fork of 4ccEditor, a save file editor for Konami's Pro Evolution Soccer 2021 (PES 2021) . The original project supports save files (`EDIT00000000`) from PES 2016 to PES 2021.

This fork aims to expand the original editor with tools for exporting player data, organizing players into custom groups, and editing multiple players at once.

## Planned Features

* [ ] Export all players from a loaded save file to TSV/CSV.
* [ ] Create and manage custom player groups using player IDs.
* [ ] Select groups of players for batch editing.
* [ ] Modify selected player attributes in bulk.
* [ ] Preview changes before applying them.

Features will be added incrementally as they are implemented and tested.

## Original Project

This project is based on [the4chancup/4ccEditor](https://github.com/the4chancup/4ccEditor). Please visit the original repository for the upstream project, its history, and existing functionality.

## Dependencies

4ccEditor depends on `libpesXcrypter.dll`, available in the `libpesXcrypter` branch of [the4chancup/pesXdecrypter](https://github.com/the4chancup/pesXdecrypter).

Refer to the original project and its build configuration for compilation requirements.
